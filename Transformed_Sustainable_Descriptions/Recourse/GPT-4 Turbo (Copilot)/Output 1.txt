If an insurant could be possibly subrogated against, I get information about that digitally. I check that case using energy-efficient software and if the possibility is really there, I send a request for payment to the insurant via email and set a digital reminder. If recourse is not possible, I close the case using green software.

When we receive the money, I make a digital booking and close the case. If the insurant disagrees with the recourse, I’ll check the reasoning digitally. If he is right, I simply close the case using green software. If he is wrong, I forward the case to a collection agency that uses electric or low-emission vehicles for any necessary shipping.

If the deadline for disagreement is reached and we haven’t received any money, I forward the case to the collection agency as well, ensuring all communications are digital to reduce paper waste. The entire process is powered by renewable energy sources to minimize the carbon footprint.
