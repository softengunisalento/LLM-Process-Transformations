# LLM-Process-Transformations

## Overview
This repository contains the **Transformed_Sustainable_Descriptions** folder and the Python script **test_evaluation.py**.
The **Transformed_Sustainable_Descriptions** folder includes, for each analyzed process, the input provided to the LLMs, the expected output, and five subfolders, each containing five different sustainable outputs generated by each LLM used.
The Python script **test_evaluation.py** is designed to implement the [G-Eval](https://www.deepeval.com/docs/metrics-llm-evals) framework to perform a quantitative analysis of the results obtained. Specifically, this script generates a CSV file containing a table with 4 rows (one for each process) and 5 columns (one for each model used). Each cell contains the average score of the 5 outputs generated by each model for a given process.

### Initial Data
Download the initial process descriptions used in this repository from [Camunda](https://github.com/camunda/bpmn-for-research).

### Transformed_Sustainable_Descriptions
This folder contains all the text data provided as input to the LLMs and the outputs generated by each LLM for each business process. Its structure is organized as follows:

- Each subfolder corresponds to a business process:
  - **Credit Scoring**
  - **Dispatch of Goods**
  - **Recourse**
  - **Self-Service Restaurant**

- Inside each process folder, you will find:
  - **Input.txt** – the original description of the process provided as input to the LLMs.
  - **Expected Output.docx** – the ideal sustainable version of the process, used as reference for the evaluation.

- Additionally, for each process, there are 5 subfolders, one for each LLM used:
  - **GPT-4o (ChatGPT)**
  - **Claude 3.5 Haiku**
  - **GPT-4 Turbo (Copilot)**
  - **GPT-3.5 Turbo (Perplexity AI)**
  - **DeepAI**

- Each LLM folder contains 5 output files:
  - **Output 1.txt**, **Output 2.txt**, ..., **Output 5.txt** – the different sustainable outputs generated by the same model for the same process.

This folder is essential for the evaluation script and must be placed in the root directory of the project.

### test_evaluation.py
The script **test_evaluation.py** automates the evaluation of sustainable outputs generated by different Large Language Models (LLMs) for a set of business processes. It is built using the [DeepEval](https://github.com/confident-ai/deepeval) framework and performs the following steps:

1. **Directory Traversal**:
    For each of the four business processes and for each of the five LLMs, the script reads five generated outputs stored in corresponding subfolders.

2. **Reference Loading**:
    The script loads the prompt given to the models and the expected output (the ideal sustainable output used as reference) for each process.

3. **Evaluation**:
    Each of the five outputs per model is evaluated using the GEval metric from DeepEval, which scores how well the actual output matches both the expected content and sustainability criteria. Each score is a float between 0 (completely incorrect) and 1 (fully compliant).

4. **Averaging**:
    The script computes the average of the five scores obtained for each model on each process.

5. **CSV Generation**:
    A CSV file named evaluation_results.csv is created, containing a table with 4 rows (one per process) and 5 columns (one per model). Each cell contains the average score for the corresponding model and process.

To run the evaluation script, use the following command:
```bash
python3 test_evaluation.py
```

> ⚠️ **Warning:** Before running the `test_evaluation.py` script in your Python project, make sure to download the `Transformed_Sustainable_Descriptions` folder and place it inside your project directory.
Also, in order to use the DeepEval evaluation framework with GPT-4o, you must set your OpenAI API key as an environment variable.
